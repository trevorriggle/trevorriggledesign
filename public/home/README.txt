Home page 2x2 tile thumbnails. Drop a file named for the tile and it
appears; no config, no manifest.

  applications.jpg   ->  the Applications tile
  design.jpg         ->  the Design tile
  agentic-ai.jpg     ->  the Agentic AI tile
  about.jpg          ->  the About tile

Any of png/jpg/jpeg/webp/avif/gif/svg. Landscape, 4:3 or wider, at least
1200px on the long edge. A tile with no file renders its title only.
